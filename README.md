# Benchmarking and generalizing robust PCA for scRNA-seq dimensionality reduction

This repository provides the analysis code and data-access provenance for the
manuscript “Benchmarking and generalizing robust PCA for scRNA-seq
dimensionality reduction.”

The manuscript Source Data and final figure files are supplied separately with
the submission and are not duplicated in this code repository. The supplied
figure scripts can regenerate the figures after the Source Data files are
placed in `Source_Data/`.

## Repository contents

| Path | Contents |
|---|---|
| `scripts/simulation/` | Clustering- and stability-simulation pipelines (`simulation1` and `simulation2` in the code), parameter grid, aggregation, and smoke test. |
| `scripts/real_data/` | PBMC, Pancreas, and Bhattacherjee preprocessing and all-method analyses. |
| `scripts/runtime/` | Matched-design runtime benchmark and aggregation. |
| `scripts/figures/` | Figure and derived-summary generation from the manuscript Source Data. |
| `data/` | Official accession links, required local layout, and verified input checksums. |
| `environment/` | Formal Linux analysis environment and local figure-generation environment. |

Raw third-party scRNA-seq files, manuscript Source Data, final figures, frozen
results, scheduler logs, and institution-specific job scripts are intentionally
not tracked in this repository.

## Formal analysis settings

- Pairwise empirical-quantile calibration with `alpha = 0.05` for the main analysis.
- `alpha = 0.10` and `0.20` only for sensitivity analysis.
- PC10 as the main dimensionality setting and PC20 as sensitivity analysis.
- Ten methods: PCA, PcaGrid, PcaHubert, PCP, K's tau, Winsor, Quad, Ball, Shell, and LR.
- Corrected doublet generation from two different unmodified background singlets.
- Ten independent simulation replicates per parameter setting.
- 2,000 HVGs, 20 randomly sampled subsets, and 10 clustering runs per embedding
  for each real dataset.
- PBMC raw rows are restricted to `feature_type == "Gene Expression"` before
  library-size normalization, log transformation, HVG selection, and scaling.
- Downstream scores are constructed as `X %*% V` for all methods except
  PcaHubert, which uses the centered scores returned by `rrcov`. This difference
  is a constant location shift: clustering comparisons are translation
  invariant, and subspace comparisons use `V` directly. For PCP, `V` is
  estimated by an uncentered, unscaled PCA of its low-rank component `L`, using
  `prcomp(L, center = FALSE, scale. = FALSE)`; `L %*% V` is not used for
  clustering or evaluation.
- GMM with candidate component counts `G = 1:15` as the primary clustering
  method; k-means and Louvain as supplementary analyses.
- Master/base seed `12345` unless explicitly overridden.

## Inputs

Simulation inputs are generated by the supplied scripts. The clustering-
simulation parameter grid is included at:

```text
scripts/simulation/formal_background_dropout_simulation/config/sim_params_1_v3.xlsx
```

Real-data inputs are obtained from their original public 10x Genomics and GEO
records. Follow `data/README.md`, place the files in the documented local
layout, and verify them from the repository root with:

```bash
md5sum -c data/DATA_MD5SUMS.txt
```

The downloaded inputs are verified against the supplied checksums before
analysis.

## Running the analyses

Simulation entry points are under:

```text
scripts/simulation/formal_background_dropout_simulation/scripts/
```

Real-data entry points are under:

```text
scripts/real_data/formal_realdata_pairwise_calibration/scripts/benchmarks/
```

Each runner accepts explicit input/output paths, method selection, seed, and
analysis parameters. See the README in each analysis directory and
`docs/reproducibility_notes.md` for the analysis settings. Full analyses,
especially Bhattacherjee and PcaGrid conditions, require substantial CPU time
and memory. No GPU is required.

## Regenerating manuscript figures

Download the Source Data supplied with the paper and place the CSV files under:

```text
Source_Data/
```

Use a UTF-8 locale when generating figures so that the qualitative symbols in
Figure 9 are preserved correctly.

Then run the relevant scripts from the repository root, for example:

```bash
Rscript scripts/figures/plot_simulation1_clustering_combined.R
Rscript scripts/figures/plot_simulation_support_from_source_data.R
Rscript scripts/figures/plot_simulation2_pcwise_from_source_data.R
Rscript scripts/figures/plot_realdata_from_source_data.R
Rscript scripts/figures/plot_runtime_from_source_data.R
Rscript scripts/figures/build_figure09_evidence.R
Rscript scripts/figures/plot_main_figures_02_09.R
Rscript scripts/figures/plot_alpha_sensitivity_from_source_data.R
Rscript scripts/figures/build_dropout_paired_comparison.R
Rscript scripts/figures/build_subspace_clustering_correlations.R
```

Generated figures are written under `figures/`, which is ignored by Git.
Figure 1 is a manually assembled study-design schematic; Figures 2--9 and
Supplementary Figures S1--S8 are generated by the scripts above. The final two
commands derive the values reported in Supplementary Tables S3 and S4.
