# Matched runtime benchmark

The benchmark uses two sweeps:

- genes: `n = 2000`, `d = 500, 1000, 2000, 3000`;
- cells: `d = 2000`, `n = 500, 1000, 2000, 3000`.

The shared `n = 2000, d = 2000` setting is generated once per replicate.
Inputs are nested subsets of five independent 3000-cell by 3000-gene matrices.
Each method uses one thread. Timing includes method fitting and 20-PC score
construction, but excludes simulation, subsetting, and preprocessing.

## Files

| Path | Purpose |
|---|---|
| `config/runtime_grid.csv` | Seven unique benchmark settings. |
| `scripts/run_runtime_task.R` | Runs one setting, replicate, and method. |
| `scripts/emit_runtime_schedule.R` | Creates the randomized call order. |
| `scripts/aggregate_runtime_results.R` | Validates and summarizes task results. |
| `scripts/plot_runtime_results.R` | Produces the runtime figure and summary. |

## Run and aggregate

Run in Bash from the repository root, with the recorded analysis packages
installed. This executes 350 fits and is intended for a compute server.
Use a fresh output directory. The schedule randomizes execution order within
each replicate; each fit runs in a separate single-threaded R process.

```bash
set -euo pipefail
RUNTIME_SCRIPTS=scripts/runtime/matched_runtime_benchmark
RUNTIME_OUT="$PWD/results/runtime"
mkdir -p "$RUNTIME_OUT/schedules"
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1
export VECLIB_MAXIMUM_THREADS=1
for rep in {1..5}; do
  Rscript "$RUNTIME_SCRIPTS/scripts/emit_runtime_schedule.R" --replicate="$rep" \
    > "$RUNTIME_OUT/schedules/rep_$rep.tsv"
  while IFS=$'\t' read -r setting method; do
    Rscript "$RUNTIME_SCRIPTS/scripts/run_runtime_task.R" \
      --setting-id="$setting" --replicate="$rep" --method="$method" \
      --repeats=5 --base-seed=12345 --alpha=0.05 \
      --output-dir="$RUNTIME_OUT/tasks"
  done < "$RUNTIME_OUT/schedules/rep_$rep.tsv"
done
Rscript "$RUNTIME_SCRIPTS/scripts/aggregate_runtime_results.R" \
  --input-dir="$RUNTIME_OUT/tasks" --output-dir="$RUNTIME_OUT/aggregated" \
  --repeats=5 --task-id-repeats=5
```

Aggregation checks all 350 task keys, failures, matched inputs, and timing
fields. Its main outputs are `runtime_benchmark_results_current.csv` and
`runtime_benchmark_summary_current.csv`. Absolute runtimes depend on hardware
and software; a new run need not reproduce the manuscript's measured seconds.

## Prepare manuscript-format Source Data

The runtime plotting utility exports the two-panel data, including the shared
anchor. Its preview uses the original runtime-job layout; the final manuscript
layout is generated by `scripts/figures/plot_runtime_from_source_data.R`.

```bash
Rscript "$RUNTIME_SCRIPTS/scripts/plot_runtime_results.R" \
  --summary-file="$RUNTIME_OUT/aggregated/runtime_benchmark_summary_current.csv" \
  --output-dir="$RUNTIME_OUT/preview" --expected-repeats=5
RUNTIME_SD="$RUNTIME_OUT/Source_Data"
mkdir -p "$RUNTIME_SD"
cp "$RUNTIME_OUT/aggregated/runtime_benchmark_results_current.csv" \
  "$RUNTIME_SD/runtime_benchmark_results_matched.csv"
cp "$RUNTIME_OUT/aggregated/runtime_benchmark_summary_current.csv" \
  "$RUNTIME_SD/runtime_benchmark_summary_matched.csv"
cp "$RUNTIME_OUT/preview/Figure08_runtime_matched_source_data_current.csv" \
  "$RUNTIME_SD/Figure08_runtime_scaling_source_data.csv"
Rscript scripts/figures/plot_runtime_from_source_data.R \
  --source-file="$RUNTIME_SD/Figure08_runtime_scaling_source_data.csv" \
  --output-dir="$RUNTIME_OUT/manuscript_figure"
```

The copies change filenames only. Font and locale requirements are documented
in [`scripts/README.md`](../../README.md). Scheduler-specific wrappers and job
files are not included.
