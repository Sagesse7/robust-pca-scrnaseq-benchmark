## Replot the supplied Source Data

This route does not rerun the experiments. Place the manuscript CSV files in
`Source_Data/` and run the commands below from the repository root. Some
scripts rewrite derived CSVs, so use a working copy of Source Data. Figure
outputs go to `figures/`.

Use a UTF-8 locale and install Arial for the recorded figure layout. Check
`Rscript -e 'stopifnot(l10n_info()[["UTF-8"]])'` before plotting. On Linux,
select an installed UTF-8 locale, such as `C.UTF-8`; the package versions are
recorded in `environment/figure_generation_package_versions.csv`.

```bash
Rscript scripts/figures/plot_simulation1_clustering_combined.R
Rscript scripts/figures/plot_simulation_support_from_source_data.R
Rscript scripts/figures/plot_simulation2_pcwise_from_source_data.R
Rscript scripts/figures/plot_realdata_from_source_data.R
Rscript scripts/figures/plot_runtime_from_source_data.R
Rscript scripts/figures/build_figure09_evidence.R
Rscript scripts/figures/plot_main_figures_02_09.R
Rscript scripts/figures/plot_alpha_sensitivity_from_source_data.R
Rscript scripts/figures/build_dropout_paired_comparison.R
Rscript scripts/figures/build_subspace_clustering_correlations.R
```

Figures S4/S5 are replotted by `plot_simulation2_pcwise_from_source_data.R`.
The separate RDS builder below is needed only when recalculating their
underlying PC-wise values. Figure 9 uses the supplied author-curated rating
table; `build_figure09_evidence.R` recalculates its quantitative evidence,
not the ratings themselves.

## Prepare Source Data after a full rerun

First follow the [simulation](simulation/formal_background_dropout_simulation/README.md),
[real-data](real_data/formal_realdata_pairwise_calibration/README.md), and
[runtime](runtime/matched_runtime_benchmark/README.md) run instructions.
The commands here use their default `results/` layout and do not fit models.
Run them from the repository root in the same Bash session, using a fresh
`results/publication/` directory to avoid mixing runs.

### Simulation aggregates

```bash
set -euo pipefail
RESULTS_ROOT="$PWD/results"
PUBLICATION_ROOT="$RESULTS_ROOT/publication"
PUBLICATION_SD="$PUBLICATION_ROOT/Source_Data"
Rscript scripts/figures/prepare_simulation_source_data.R \
  --simulation1-dir="$RESULTS_ROOT/simulation1" --simulation2-dir="$RESULTS_ROOT/simulation2" \
  --rds-root="$RESULTS_ROOT" --output-dir="$PUBLICATION_SD"
```

This exports the two main simulation inputs, Figure S6 PC10/PC20 values,
Figure S8 alpha comparisons, and Table S2 diagnostics. It selects the primary
alpha where appropriate, preserves all displayed settings, standardizes method
labels, and makes RDS paths relative to `--rds-root`. No fitted results are
changed. For archived aggregates, `--rds-root` must match the original common
path prefix recorded in their `CleanPath` and `RDS_Path` columns. The optional
`--qc-source` changes only the diagnostic table's provenance label; the supplied
manuscript table uses `Formal 2026-07-18/19 rerun`.

### PC-wise values from saved loadings

```bash
Rscript scripts/figures/build_simulation2_pcwise_from_formal_rds.R \
  "$RESULTS_ROOT" "$PUBLICATION_SD/subspace_figures_input_alpha005.csv" "$PUBLICATION_ROOT"
```

The three positional arguments are the RDS path root, the primary stability
CSV, and an output root. The last argument is named `latex_journal_root` in
the script, but no LaTeX files are required. The script writes S4/S5 CSVs
under `Source_Data/` and preview figures under `Appendix/`. It verifies
reference/perturbed metadata and checks recomputed subspace values against
the stability aggregate. Saved RDS files are generated by the simulation
runners and are not distributed with the code package.

### Real-data results

```bash
Rscript scripts/figures/prepare_figure06_hierarchical_source_data.R \
  --pbmc-dir="$RESULTS_ROOT/real_data/pbmcs" \
  --pancreas-dir="$RESULTS_ROOT/real_data/pancreas" \
  --bhattacherjee-dir="$RESULTS_ROOT/real_data/bhattacherjee" \
  --output="$PUBLICATION_SD/Figure06_realdata_gmm_pc10_ari_source_data.csv" \
  --subspace-output="$PUBLICATION_SD/Figure07_realdata_subspace_pc10_source_data.csv" \
  --sensitivity-output="$PUBLICATION_SD/FigureS07_realdata_pc10_vs_pc20_gmm_reproducibility_source_data.csv"
```

The builder retains the Figure 6 clustering-run hierarchy and exports one
Figure 7 subspace value per subset. Figure S7 uses the same repeated-clustering
CSV inputs. Optional `--pbmc-status`, `--pancreas-status`, and
`--bhattacherjee-status` set provenance text only. For the supplied manuscript
files, all three were `validated merged formal result; PCP XV corrected`;
new runs use `manuscript analysis` unless a status is explicitly supplied.

### Runtime and final plots

After the runtime README's export step:

```bash
cp "$RESULTS_ROOT/runtime/Source_Data/runtime_benchmark_results_matched.csv" "$PUBLICATION_SD/"
cp "$RESULTS_ROOT/runtime/Source_Data/runtime_benchmark_summary_matched.csv" "$PUBLICATION_SD/"
cp "$RESULTS_ROOT/runtime/Source_Data/Figure08_runtime_scaling_source_data.csv" "$PUBLICATION_SD/"
```

For final plotting, use a separate working copy of this repository containing
the supplied Source Data, replace the regenerated CSVs with those from `$PUBLICATION_SD`,
and run the replot commands above. Keep the supplied Figure 9 rating table as
an author-assigned input rather than treating it as an automatically derived
result. Compare regenerated scientific values before replacing manuscript
files; runtime measurements and run-specific metadata can differ on a new run.
